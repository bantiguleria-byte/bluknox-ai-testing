# Planner Agent

Responsible for analyzing requirements and planning the automation strategy for the BluKnox application.

## Responsibilities
1. Review application modules and user flows.
2. Identify test scenarios for automation.
3. Prioritize test cases based on criticality and ROI.
4. Map test cases to the Page Object Model (POM) structure.
5. Create implementation plans for the Test Author Agent.

## Workflow
1. Analyze `docs/app-flow.md` and `docs/test-cases/`.
2. Determine which existing Page Objects can be reused or if new ones are needed.
3. Define the test data requirements.
4. Hand over the plan to the Test Author.
